# Golden sets de citas

Casos de prueba para evaluación continua. Cada caso indica pregunta, `source_ids` esperados, nivel mínimo V y respuesta correcta o `ABSTENER`.

```markdown
## Caso 1
Pregunta: ¿qué tasa tiene el ITBMS general?
source_ids: PA-FIS-000
Respuesta: 7% general; tasas especiales requieren fuente adicional.
Estado: pendiente de verificación V.
```

La prueba de abstención es obligatoria: una pregunta sin fuente en el corpus debe devolver «sin fuente verificada».
