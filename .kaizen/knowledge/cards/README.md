# Cards por rol

Cada `cards/<rol>.md` resume para un puesto: fuentes obligatorias (ids), preguntas que puede responder, límites y siguiente escalado. Plantilla:

```markdown
# <rol>
- Fuentes obligatorias: PA-XXX-000 (nivel V), INT-STD-000
- Preguntas que responde: <…>
- No responde sin humano: <…>
- Escalado: verificador-evidencias / humano
```
