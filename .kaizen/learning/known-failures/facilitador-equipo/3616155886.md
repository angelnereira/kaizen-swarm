# Fallo conocido: jq false//default oculta disabled=false

## Síntoma
jq imprime unset aunque el campo disabled vale false

## Causa y fix aplicado
usar .disabled|tostring en lugar de .disabled // "unset"

## Regla para no repetirlo
Nunca usar el operador // sobre booleanos en jq: false es falsy y se sustituye por el default
