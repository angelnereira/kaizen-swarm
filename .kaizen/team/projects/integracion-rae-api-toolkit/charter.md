# Charter: integracion-rae-api-toolkit

## Objetivo
Integrar reverse-api-engineer como toolkit gobernado con agente especializado, y decidir con evidencia si la ruta nativa (REA + automatizacion propia) sustituye la dependencia del repositorio externo

## KPI verificable
1 captura de prueba en sitio propio autorizado con run_id + HAR saneado + coste registrado; 100% de decisiones con source_ids verified y kaizen-team verify en verde; 0 secretos en artefactos; ADR comparativo externo vs nativo con dictamen de arquitecto y security y aprobacion humana

## Restricciones
- Decisiones con fuentes verificadas: .kaizen/team/EVIDENCIA.md
- Vetos: security, architecture, qa, compliance, scope, resource
- Proactividad con frenos: .kaizen/team/FLUJOS.md
