# Loop PRODUCT: del uso real a propuestas de features

1. Lee `docs/kaizen/data/insights/latest.json` (uso, errores, rendimiento) y los issues con etiqueta `feedback`.
2. Identifica patrones: funciones muy usadas con fricción, flujos con muchos errores, funciones nunca usadas, tareas repetitivas automatizables.
3. Redacta hasta 3 propuestas en `docs/kaizen/proposals/NNNN-titulo.md`: problema, evidencia, solución mínima, métrica de éxito, riesgos, privacidad y RICE.
4. Abre un issue por propuesta con etiqueta `proposal` (NO `kaizen:ready`). Una persona decide si pasa a `kaizen:ready`.
5. No implementes features sin esa aprobación, en ningún nivel de autonomía.
